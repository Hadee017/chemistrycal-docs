# Chemistrycal Technical Documentation

Welcome to the official technical documentation and methodology guide for **[Chemistrycal](https://chemistrycal.com)**, an open-access benchtop computational suite engineered for students, educators, and analytical laboratory researchers.

## Overview & Purpose

Chemistrycal provides client-side computational modules for general chemistry, solution preparation, stoichiometry, and materials characterization. All algorithms execute locally within your browser to ensure offline accessibility and complete data privacy.

* **Official Web Application:** [Chemistrycal Benchtop Studio](https://chemistrycal.com)
* **Creator:** Bilal Khan (MS Chemistry Researcher, University of Education Lahore)
* **CERN Zenodo Archive:** [DOI 10.5281/zenodo.23059466](https://zenodo.org/records/23059466)
* **ORCID Profile:** [0009-0006-3082-7043](https://orcid.org/0009-0006-3082-7043)

## Core Computational Modules

Explore our key online tools directly on the main platform:
* **[Molarity Calculator](https://chemistrycal.com/molarity):** Computes precise solute mass compensating for hydrate water and assay purity percentages.
* **[C1V1 = C2V2 Dilution Calculator](https://chemistrycal.com/dilution):** Stock aliquot and solvent volume solver for serial dilution ladders.
* **[PXRD Scherrer Crystallite Size Calculator](https://chemistrycal.com/scherrer):** Evaluates mean domain size from powder X-ray diffraction peak FWHM.
